1. MiniMind 是什么

MiniMind 用极简代码实现了一个完整的语言模型训练链路：从分词、预训练、指令微调，到 LoRA、蒸馏、DPO、强化学习， 每一环都能在单张消费级显卡上跑完。它最大的教学价值，是“短”——短到你能逐行读懂。

4. 用 uv 管理环境

本项目用 uv 管理依赖。所有依赖都写在 pyproject.toml 里，uv.lock 锁定精确版本。

# 创建环境并安装全部依赖
uv sync

# 启动 JupyterLab
uv run jupyter lab

# 临时加一个包
uv add matplotlib

# 只在训练阶段安装可选依赖
uv sync --extra train
✅ 为什么用 uv
它比 pip 快一个数量级，并且 uv.lock 保证你和别人装出完全一致的版本——深度学习里这点极其重要。
