RMSNorm 均方根归一化

深度网络里，激活值的尺度会层层漂移。归一化把每层的数值“拉回”同一量级，让训练稳定。RMSNorm 是 LayerNorm 的极简版本——只除均方根，不减均值、不学偏置。

Pre-Norm eps = 1e-6 可学习权重 γ 尺度不变性

1. 公式只有一行

RMS(x) = sqrt( mean(x²) + eps )
RMSNorm(x) = γ ⊙ x / RMS(x)

# 对比 LayerNorm：
LayerNorm(x) = γ ⊙ (x - μ) / sqrt(σ² + eps) + β

LayerNorm 要减均值、算方差、还要偏置 β；RMSNorm 只保留“按能量缩放”这一件事。 实测效果几乎一样，但少一次减均值和一次求方差，更快。

🔑 尺度不变性
RMSNorm(k·x) = RMSNorm(x)。正因为这个性质，前向传播中即使某层激活值突然放大 10 倍， 归一化也会把它拉回原尺度——这正是深层 Transformer 能稳定训练的关键。
