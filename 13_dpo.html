DPO 直接偏好优化

强化学习能让模型对齐人类偏好，但需要训练奖励模型、跑在线采样，复杂且不稳定。DPO 把这一整套“魔法”化简成一个二分类式的损失函数——只用现成的“好答案 / 坏答案”数据就能对齐。

chosen / rejected 参考模型 π_ref β 温度 离线偏好数据

1. 一个损失函数搞定

ratio_w = logπ(y_w|x) − logπ_ref(y_w|x)     # 好答案相对参考模型的提升
ratio_l = logπ(y_l|x) − logπ_ref(y_l|x)     # 坏答案的提升

loss = −log σ( β · (ratio_w − ratio_l) )

直观理解：让“好答案”相对参考模型被抬得更高，让“坏答案”被压得更低。 σ 把差距映射成概率，取负对数就是“希望差距越大越好”。

🔑 参考模型的作用
π_ref 是冻结的 SFT 模型。减掉它的 log 概率，相当于只奖励“比原来更好的变化”， 防止模型为了刷分而偏离语言本身（这也是 KL 正则的隐式形式）。

✅ 动手提示
Notebook 里先带你练 F.log_softmax + gather 取“某位置某 token 的 log 概率”、 F.logsigmoid、以及用 loss_mask 只累加回答 token 的对数概率， 再留白让你实现 dpo_loss。难点是 把逐 token 的 logprob 按 mask 求和， 得到整条回答的 log 概率。
