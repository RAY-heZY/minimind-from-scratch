因果自注意力与 GQA / KV Cache

注意力是 Transformer 的心脏：每个 token 向所有 token 提问（Query），拿回答案（Key/Value）加权求和。“因果”意味着不能偷看未来；“GQA”让推理更省显存；“KV Cache”让逐词生成不必重复计算。

缩放点积 causal mask 8 Q 头 / 4 KV 头 SDPA

1. 四步走完注意力

scores = (Q @ Kᵀ) / sqrt(head_dim)      # 1. 打分
scores = scores + causal_mask           # 2. 遮住未来（上三角 = -inf）
attn   = softmax(scores, dim=-1)        # 3. 归一化成权重
out    = attn @ V                       # 4. 加权求和

3. GQA：让多个 Query 头共享一个 KV 头

标准多头注意力里 Q、K、V 头数相同，KV 占显存大。MiniMind 用 8 个 Q 头 : 4 个 KV 头， 每 2 个 Q 头共享 1 组 KV——质量几乎不掉，KV 显存直接减半。

示意分组查询注意力（GQA）

4. 动画：KV Cache 增量解码

生成第 t 个词时，前 t−1 个词的 K、V 和之前算过的一样，没必要重算。 把它们缓存起来，每步只算 1 个新 token 的 Q、K、V。
