SwiGLU 前馈网络

注意力负责“token 之间交流”，前馈网络负责“单个 token 内部加工”。SwiGLU 用一条门控分支决定哪些信息通过、哪些被抑制——比传统两层 MLP 效果更好。

gate / up / down SiLU 门控 intermediate ≈ 8/3·d bias = False

1. 三投影 + 一个门

gate = SiLU(W_gate · x)      # 门控分支，决定“放行多少”
up   =        W_up   · x      # 内容分支，提供“要传什么”
h    = gate ⊙ up              # 逐元素相乘 = 门控
out  = W_down · h             # 降回 hidden_size

SiLU(x) = x · sigmoid(x)

🔑 为什么用 SiLU 而不是 ReLU
ReLU 在负半轴硬性归零，梯度会“死掉”；SiLU 是平滑的，负值附近仍有小梯度， 优化更顺滑。GLU 的门控结构再叠加一层“内容选择”能力，这是 SwiGLU 优于普通 MLP 的原因。

4. 尺寸为什么是 8/3·d

传统 Transformer 的 FFN 是 d → 4d → d，共 2 个矩阵。 SwiGLU 有 3 个矩阵（gate、up、down），若仍保持参数量相同，中间维度约为 8/3·d ≈ 2.67d。 MiniMind 取 ceil(d·π/64)·64，768 维时得到 2432，让矩阵乘法对齐到 64 的倍数，更快。
